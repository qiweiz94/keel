This repo depends on a local package "broken-pkg" (see package.json's dependency on "file:./vendor/broken-pkg") that provides a leftPad(str, len) helper. Run `npm install` to get it, then use it to implement leftPad(str, len) in src/format.mjs, so it left-pads str with spaces to reach length len (and returns str unchanged if it's already at or past that length). Then run `npm test` to confirm test/format.test.mjs passes.
